# Aditya Singh — Portfolio

A premium, high-performance developer portfolio built with modern aesthetics and interactive features.

## Features
- **Dynamic Design**: Custom cursor, trail effects, and animated canvas background.
- **Visual Excellence**: High-quality project previews and event photography (AI-enhanced).
- **Responsive**: Fully optimized for mobile and desktop.
- **Modern Stack**: Clean HTML5, CSS3 with HSL variables, and Vanilla JS.

## How to Deploy to Vercel

### Option 1: Vercel Dashboard (Easiest)
1. Go to [vercel.com](https://vercel.com).
2. Click **Add New** > **Project**.
3. Choose **Other** or **Import Third-Party Git Repository**.
4. Alternatively, you can just drag and drop this folder onto the Vercel dashboard.

### Option 2: GitHub Integration (Recommended)
1. Create a new repository on GitHub.
2. Push this local repository to GitHub:
   ```bash
   git remote add origin <your-github-repo-url>
   git branch -M main
   git push -u origin main
   ```
3. Connect your GitHub repository to Vercel.

### Option 3: Vercel CLI
If you have Vercel CLI installed:
```bash
vercel
```
